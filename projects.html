Internship Project  ·  Tata Steel

Industrial Dispatch & White Rust RCA Dashboard

My first professional data project — built during a 4-week Data Analytics internship at Tata Steel, July 2026. Cleaned and profiled a masked industrial dispatch dataset, resolving missing values, duplicate columns, and inconsistencies across 6+ operational fields to make it analysis-ready.

Designed and built an interactive Power BI dashboard converting raw dispatch, freight, transit-time, and material-distribution data into a self-explanatory view for first-time stakeholders. Extended it into a White Rust Root Cause Analysis (RCA) support tool, tracking KPIs across plants, transporters, and destinations for the investigation team. Presented findings directly to the project guide across two rounds of feedback — and saw the dashboard adopted by the team.

  • Power BI
  • DAX
  • Power Query
  • Data Cleaning
  • Root Cause Analysis
  • Stakeholder Reporting
